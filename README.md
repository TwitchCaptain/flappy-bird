# Flappy Bird

A lightweight Flappy Bird clone built with pure Canvas and JavaScript — no frameworks, no external image or audio assets.

**Play:** [twitchcaptain.com/flappy-bird](https://twitchcaptain.com/flappy-bird/)

## Controls

- Tap / click the game
- Space, ↑, or W

## Features

- Procedural bird, pipes, clouds, and ground
- Web Audio beeps for flap / score / hit
- Local high score
- Sky palette shifts every **5** pipes cleared
- Pipe palette shifts every **9** pipes spawned

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
